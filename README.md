# Chat Media Collector

The website of Chat Media Collector by Orbit Fox Studio, a Windows app in the Microsoft Store that saves a Telegram
chat's photos and videos into one folder, in posting order:

- Home page: https://orbitfoxstudio.github.io/chat-media-collector/
- Privacy policy: https://orbitfoxstudio.github.io/chat-media-collector/privacy/
- Microsoft Store: https://apps.microsoft.com/detail/9PD8CH2DHF9C

Chat Media Collector is an unofficial app. It isn't made by or affiliated with Telegram.
